# The Treasury Box ｜ 白日夢願景顯像盒 ✨

> 一款純前端、零依賴、無須後端伺服器的互動式心願孵化與向量幻獸顯化網頁應用程式。支援 GitHub Pages 一鍵直接線上體驗！

---

## 🌟 專案特色

- **純前端極致輕量**：單一 HTML 搭配在地化像素背景，無任何外部 CDN、資料庫或伺服器依賴，支援 100% 離線運行。
- **3D 擬真神聖寶箱**：
  - 24K 金屬包角飾條、光澤流光動態、懸浮璀璨星塵與羽翼寶石鎖。
  - **點擊手感回饋**：點擊晃動寶箱並發出擬真金幣碰撞聲響（純 Web Audio API 實時音訊合成）。
  - **隱藏寶箱怪（Mimic）型態**：選擇特定流派時動態甦醒，長出尖銳獠牙、豎瞳魔眼與晃動長舌，伴隨震撼猛獸低吼咬合音效。
- **兩階段流暢引導體驗（Two-Step Stepper）**：
  - **Step 1**：挑選 9 大願景陣營（暴富、躺平、享樂、療癒、科技、智慧、聚光、自由、靈感），卡片支援觸控與鍵盤導航。
  - **Step 2**：具象化心願填寫，內建靈感快捷標籤。
- **盲測情緒辨識引擎**：
  - 自動依據學生輸入文字的情感傾向，動態判定孵化出「亮晶晶眼睛」或「暈眩／死魚眼」表情，開箱前全程保密，揭曉時帶來十足驚喜！
- **拍立得卡片生成與匯出**：
  - 自動合成 1200 x 1820 高畫質拍立得復古收藏卡片，支援一鍵下載 PNG。

## 🚀 部署至 GitHub Pages（供學生免安裝線上使用）

1. 將本專案推送至 GitHub Repository。
2. 進入該專案的 **Settings** ➜ **Pages**。
3. 在 **Build and deployment** 底下的 **Source** 選擇 `Deploy from a branch`。
4. Branch 選擇 `main` / `root`，點擊 **Save**。
5. 等待 1~2 分鐘，即可獲得公開的網址（例如：`https://<你的帳號>.github.io/<專案名稱>/`），直接分享給學生遊玩！
